# Tutoriales Para el Curso de Estadística

Este repositorio contiene los tutoriales necesarios para el curso de Estadística. Los tutoriales se van a encontrar en la carpeta `tutoriales/` y van a tener videos explicativos asociados. 

## 1. Tutorial de Conda, Git y GitHub

Este tutorial tiene como objetivo que aprendan a gestionar un proyecto de datos y a utilizar herramientas de gestión de entornos (Conda) y gestión de versiones (Git y GitHub). Se pueden ver los videos explicativos en los siguientes enlaces:
1. [Tutorial 1: Crear Repositorio de Tareas, Entornos de Conda y Git.](https://youtu.be/4mYglDhxnlQ)
2. [Tutorial 2: Editor de Código y GitHub](https://youtu.be/aYqewtou72k)

## 2. Tutorial de NumPy, Pandas y Matplotlib

Este tutorial tiene como objetivo introducir las librerías más utilizadas en el análisis de datos con Python. Se pueden ver los videos explicativos en los siguientes enlaces:
1. [Tutorial 3: NumPy, Pandas y Matplotlib](https://youtu.be/8SVjwY6cHuU)
